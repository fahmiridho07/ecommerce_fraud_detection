# Kaggle Standalone Scripts

This folder preserves one-cell Kaggle/Colab-style experiment scripts used for
external reproduction, full-data memory relief, or advisor-facing validation.

They are archived because the canonical local thesis workflow now lives in
`src/` and is tracked through `docs/EXPERIMENT_REGISTRY.md`. Keep these scripts
for traceability, but do not treat them as active entrypoints unless the scope is
reopened and the registry is updated.
